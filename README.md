# 🐾 猫咪控糖日记 (Cat Diabetes Tracker)

> **版本**：`v1.4.0`  
> **项目备注**：新增自动喂食机定时出粮云端托管与智能对齐引擎，升级历史 Excel 数据智能解析导入，全面优化临床级数据导出与无 Emoji 专业医疗交互体验。

「猫咪控糖日记」是一款专为糖尿病患猫（糖猫）家庭打造的微信小程序。它致力于帮助宠物主人科学、系统地记录和追踪猫咪的血糖、打针、定时饮食、排泄与体重数据，辅助日常病情管理与临床就诊复查。

---

## ✨ 核心功能

- 🐈 **多猫档案管理**：支持记录多只猫咪的基础信息、确诊时间及个性化的血糖控制目标（安全目标范围及高低危险阈值警告）。
- 👨‍👩‍👧‍👦 **家庭成员共享**：支持通过微信转发邀请家人或兽医一起管理猫咪档案，数据云端双向同步，多端实时可见。
- 🩸 **多维健康指标记录**：
  - **血糖与打针**：快捷记录每日各时段血糖数值（早针前、针后峰值、晚针前等）和胰岛素注射剂量。
  - **饮食与喂食**：记录单次进食克数、罐头品牌批次、附带补剂用药（益生菌、鱼油、皮下补水等）与备注。
  - **排泄与粪便评分**：记录每日排尿团数与排便形态特征。
  - **体重追踪**：精准记录每次称重时间与体重数值，防止体重异常波动。
- 🤖 **自动喂食机托管系统 (Auto-Feeder Cloud Engine)**：
  - **定时出餐计划**：针对少食多餐控糖场景，支持一键套用 8顿/6顿/4顿 定时出粮方案，自定义各顿时间与克数。
  - **云端持久化存储**：配置双写云端数据库与本地缓存，彻底解决清除缓存/换手机丢失配置的问题，全家共享出餐时刻。
  - **智能时钟对齐（Smart Catch-Up）**：小程序唤醒时毫秒级自动对齐并补齐今日已到达出餐点的饮食记录，无需手动重复打卡。
- 📥 **历史 Excel 数据智能导入 (Intelligent Excel Import)**：
  - **智能识别**：支持从微信会话上传历史 Excel 表格，自动解析血糖、打针、多餐定时饮食、排泄、体重等 5 大维度记录。
  - **高级解析引擎**：支持跨行合并单元格品牌继承、模糊时序识别、智能餐次阶段划分与精确去重防重入机制。
- 📊 **临床级就诊 Excel 报告导出 (Clinical Export)**：
  - 支持导出最近 30 天或全量历史记录，采用时序平铺与医疗色彩分区，方便就诊时直接发送给主治兽医师。
- 📈 **数据可视化与历史回溯**：主页支持血糖与体重折线图一键切换对比，支持触控横向平移与阈值警戒线；提供“历史数据”长列表随时回溯与整理。
- 🛠️ **实用医学小工具**：
  - **单位换算器**：一键进行 `mg/dL` 和 `mmol/L` 的互换。
  - **碳水干物质计算器**：支持拍摄猫粮包装营养成分表进行 **📸 智能 AI 识别**，自动提取水分、粗蛋白、粗脂肪并计算干物质碳水化合物（DMB）。
  - **医疗提醒**：支持定制化微信服务通知定时提醒。

## 🛠️ 技术栈

- **前端框架**：[Uni-app](https://uniapp.dcloud.net.cn/) + Vue 3 + Vite + TypeScript
- **UI & 样式**：纯原生 CSS 精心打磨（杜绝 Emoji，全流程采用专业医疗 SVG 矢量图标，极小包体积）
- **图表渲染**：[uCharts](https://www.ucharts.cn/) (通过 uni-modules 引入)
- **后端服务**：微信小程序·云开发（Serverless）
  - **云数据库 (Cloud Database)**：存储猫咪档案、血糖、打针、饮食、排泄、体重与喂食机托管配置
  - **云函数 (Cloud Functions)**：
    - `api`：核心业务 CRUD 接口、家庭共享绑定、喂食托管配置存取、OCR 图像解析
    - `importExcel`：历史 Excel 智能解析与批量安全入库
    - `exportExcel`：基于 ExcelJS 生成临床就诊彩色报告

## 🚀 部署与运行指南

### 1. 环境准备
- 安装 [Node.js](https://nodejs.org/) (推荐 v16+ 或 v18+)
- 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)

### 2. 依赖安装与构建
在 `frontend` 目录下打开终端，依次执行：

```bash
# 1. 安装前端依赖
npm install

# 2. 构建正式版微信小程序包
npm run build:mp-weixin
```

### 3. 在微信开发者工具中导入与部署
1. 打开微信开发者工具，选择 **“导入项目”**；
2. 项目根目录选择当前工程根目录；
3. 输入你的小程序 `AppID`；
4. 点击顶部工具栏的 **“云开发”** 开通云开发环境；
5. 在左侧目录树中，分别对 `cloudfunctions` 文件夹下的云函数右键点击 **“上传并部署：云端安装依赖”**：
   - `cloudfunctions/api`
   - `cloudfunctions/importExcel`
   - `cloudfunctions/exportExcel`
